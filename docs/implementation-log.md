## 27 ноября 2026 — удаление пяти геонастроек

Удалены точность, высота, точность высоты, скорость и направление из формы, сводки, текущего профиля, нового примера и экспорта. Internal/portable schema 3 принимает в geolocation только latitude/longitude. Старые schema/fixture v1/v2 сохранены; их reader проверяет исходный контракт, удаляет упразднённые поля и сохраняет остальные настройки. Предпросмотр поясняет удаление. Чтение старого локального профиля нормализует его без записи, следующее сохранение или импорт записывает v3.

Геомодуль больше не создаёт полную фиксированную позицию: native get/watch обеспечивает остальные значения, timestamp, options, ошибки и диалог разрешения. Добавлены проверки сохранения пяти полей, отказа от старых подмен даже в устаревшем входе runtime, миграции/экспорта v3, отсутствия удалённых инпутов, новых наблюдений и очистки. ## 26 ноября 2026 — необязательные поля и перенос частичных профилей

В профиле обязательно только название. Пустые инпуты означают отсутствие подмены, ноль сохраняется, явное unknown остаётся null для четырёх nullable-геополей. Валидация собирает ошибки всех заполненных полей и показывает их после взаимодействия с полем либо попытки сохранения. Начало ввода названия не вызывает ошибку широты.

Частичные get/watch сливают только выбранные координаты с нативным ответом и сохраняют его время, опции, ошибки и разрешения. Незаданные языки не устанавливают navigator или сетевые правила; локаль и пояс независимы, системная карта не захватывается. Portable config v2 и внутренний профиль v2 сохраняют отсутствие каждого поля; reader v1 и fixture/schema v1 сохранены. Проверки включают импорт поверх полного профиля с удалением старых правил и перенос одного JSON с одной широтой между двумя различающимися синтетическими окружениями. Приёмка установленного Chrome остаётся отдельной незавершённой проверкой.

## 24 ноября 2026 — JSON конфигурации

Стабильный reader v1 и отдельный адаптер старого JSON профиля сохраняют прежнее поведение; будущие схемы и неизвестные поля отклоняются без записи. Профиль, сайты, UI и подсказки доступов переносятся без служебной диагностики и метаданных компьютера.

Импорт сериализован общей очередью, отключает старые регистрации, использует сохраняемый журнал отката и проверяет результат чтением. Язык/тема доставляются через локальную запись с подтверждением обработки, включая закрытие UI. Доступы выдаются отдельным пользовательским действием; применение и прежняя проверка Chrome сохраняются. Добавлены unit/DOM проверки формата, старых файлов, приватности, конфликтов, неоднозначной/частичной записи, перезапуска, скачивания и действительной очистки активного backend в синтетическом окружении. ## 12 ноября 2026 — I22: документы и границы покрытия

FrameRegistry различает active/cached/unconfirmed/prerender, ожидаемые и фактические revision и implementation 6.
