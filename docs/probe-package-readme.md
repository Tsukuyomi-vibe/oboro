# Oboro Check — версия 0.3.1

[English](probe-package-readme.en.md) | **Русский**

Пакет включает отдельное диагностическое расширение **oboro — diagnostics**, папку dist-probe и локальный сервер Oboro Check. Диагностика имеет доступ только к четырём localhost-хостам и проверяет раннюю инъекцию и сетевые правила.

Страница расширения открывается на английском. Поле **Language → Русский** вверху переключает интерфейс на русский и сохраняет выбор локально. У диагностического и основного расширений отдельные настройки языка.

1. Нужна поддерживаемая ветка Node.js: 22.22.2+, 24.15.0+ или 26+. Из распакованной папки выполните `node fixtures/i02/server.mjs`. npm-зависимости серверу не нужны. Остановка — Ctrl+C.
2. Откройте показанный сервером адрес selected.localhost:8787. Сначала сохраните исходный серверный JSON без установленной или активной диагностической сборки.
3. Загрузите папку dist-probe в chrome://extensions как распакованное расширение. Откройте страницу диагностики через его значок.
4. Укажите исходный JSON, проверьте точную версию Chrome и доступность API при выключенном и включённом переключателе пользовательских скриптов. Пройдите baseline → armed → off, выполните очистку собственных регистраций и правил, экспортируйте полный JSON.
5. Выключите диагностическое расширение после очистки. Импортируйте полный отчёт в обычное oboro 0.3.1. Оно повторно проверит точную версию Chrome и доступность API.

Темы «Как в системе», «Светлая» и «Тёмная» доступны на странице диагностики и в Oboro Check. Палитра общая с основным расширением. Выбор сохраняется локально для соответствующего origin; у диагностического и основного расширений разные хранилища.

На странице есть проверки SPA, BFCache, новой вкладки, ранних iframe/srcdoc/blob и workers. BFCache подтверждается только фактическим pageshow.persisted=true. Workers и непрозрачные контексты не покрываются базовой инъекцией.

Геолокация и карта клавиатуры запрашиваются вручную. Введённый текст, события клавиатуры и координаты остаются на странице и не отправляются в серверный журнал. Автоматизированные проверки не заменяют приёмку в установленном Chrome Stable/Beta.
