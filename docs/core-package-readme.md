# oboro — версия 0.3.3

[English](core-package-readme.en.md) | **Русский**

Расширение задаёт региональный профиль для выбранных сайтов. В версии 0.3.3 обязательно только название; все остальные поля независимы и необязательны. Из геопараметров остаются только широта и долгота. Пустые значения сохраняют исходные данные браузера на каждом ПК. [Изменения версии](releases/0.3.3.md).

**Проверка совместимости в установленном Chrome Stable/Beta ещё не завершена.** Перед включением подмен нужен полный успешный отчёт для точной версии Chrome. [Матрица приёмки](core-acceptance-matrix.json).

Исправлена конфиденциальность диагностического обмена: страница не получает список разрешённых сайтов и общий идентификатор применения. После обновления перезагрузите ранее обработанные страницы. Пакет содержит обезличенную сводку проверок без сырых логов. [Данные и ограничения](privacy.md).

## Установка и обновление

1. Распакуйте oboro-0.3.3.zip. Откройте chrome://extensions в Chrome.
2. Включите режим разработчика, выберите «Загрузить распакованное расширение» и папку **dist** из распакованного пакета.
3. Для обновления уже установленной локальной сборки замените файлы в прежней папке dist и нажмите кнопку перезагрузки на карточке расширения. При работе из проекта прежний путь остаётся тем же. Название в карточке изменится на oboro.
4. В сведениях о расширении разрешите пользовательские скрипты, если Chrome показывает этот переключатель. После изменения перезагрузите расширение.
5. Откройте настройки кнопкой **Open settings** из popup. Интерфейс по умолчанию английский; поле **Language → Русский** переключает его на русский и сохраняет выбор. Язык и тема выбираются вверху настроек и внизу popup. «Как в системе» учитывает настройки ОС; явный выбор сохраняется локально. Язык интерфейса не меняет языки регионального профиля.
6. Задайте название и нужные подмены, затем сохраните. Только название обязательно; пустые поля оставляют исходные значения браузера. Ноль — заданная координата. В геолокации меняются только широта и долгота. Выберите сайты и выдайте доступы. Пустой список выбранных сайтов ничего не включает; исключения имеют приоритет.
7. Перед применением получите отчёт через пакет **oboro-probe-0.3.3.zip** с локальным Oboro Check и диагностическим расширением dist-probe. Завершите пробу и очистку, выключите диагностическое расширение и импортируйте полный JSON в обычном расширении.
8. Нажмите «Применить и перезагрузить выбранные страницы». Для выбранного iframe на другом сайте может понадобиться ручная перезагрузка родительской страницы.

## Резервная копия конфигурации

В настройках откройте **Резервная копия конфигурации** и нажмите **Экспортировать сохранённую конфигурацию**. JSON содержит сохранённые профиль, сайты, язык/тему, подсказки доступов, обязательную oboroVersion и отдельную schemaVersion. Несохранённые правки и служебная диагностика не включаются. Файл содержит приватные координаты и сайты; храните его приватно.

Выберите JSON, проверьте изменения и нажмите **Импортировать эти настройки**. Текущая схема — v3: незаданные поля остаются исходными на каждом ПК. Профиль с одной широтой после переноса меняет только широту. При импорте v1/v2 пять удалённых геонастроек отбрасываются с пояснением в предпросмотре; остальные настройки сохраняются. Отдельные профили v1/v2/v3 восстанавливают только профиль. Полный импорт оставляет подмены выключенными и сохраняет доступы Chrome; недостающие разрешения выдаются отдельной кнопкой. Режим всех доступных сайтов использует разрешения текущего браузера. Примените профиль отдельно после проверки совместимости и перезагрузите страницы. Будущая схема отклоняется без изменений; для прерванной записи есть журнал отката. [Контракт формата](configuration-format.md), [схема v3](../schemas/oboro-config.v3.schema.json), [сохранённая схема v2](../schemas/oboro-config.v2.schema.json), [сохранённая схема v1](../schemas/oboro-config.v1.schema.json).

## Выключение и ограничения

Общий выключатель снимает будущие регистрации и сетевые правила. Для возврата исходных API перезагрузите ранее обработанные страницы. При неподтверждённой очистке доступна команда «Отключить и повторить очистку».

Date, Intl и доступный Temporal.Now используют часовой пояс профиля, если он задан. Пустые пояс и локаль сохраняют исходные значения независимо друг от друга. Явно заданные зоны и абсолютное время сохраняются. При включённой подмене времени неоднозначные строки дат вроде 01/02/2024 дают Invalid Date/NaN. Отсутствующий Temporal не создаётся.

Карта раскладки изменяет getLayoutMap. Физический ввод, key/code, сочетания и IME остаются системными. Частичная геолокация требует нативной позиции и разрешения, меняет только заданные поля и сохраняет ошибки браузера. Точность, высота, точность высоты, скорость и направление всегда сохраняются из ответа браузера. После возврата из кэша страницы для геонаблюдений может потребоваться перезагрузка.

Workers, непрозрачные контексты и неизвестный origin не получают базовую подмену. IP и хранилища сайтов не изменяются. Диагностика показывает наблюдавшиеся документы и ограничения; она не подтверждает отсутствие всех утечек.

Разрешения: storage, activeTab, userScripts, scripting, declarativeNetRequestWithHostAccess, webNavigation. Доступ к HTTP/HTTPS-сайтам выдаётся отдельно. Удалённый исполняемый код отсутствует. Архивы не подписаны и не опубликованы в магазине; контрольные суммы находятся в SHA256SUMS.txt.
