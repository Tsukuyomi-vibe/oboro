# oboro — версия 0.3.1

[English](core-package-readme.en.md) | **Русский**

Расширение задаёт региональный профиль для выбранных сайтов. Версия 0.3.1 обновляет название, подписи проверки совместимости и оформление. Добавлены системная, светлая и тёмная темы «Туман и нефрит»; явный выбор сохраняется и имеет приоритет над системной темой. [Изменения версии](releases/0.3.1.md).

**Проверка совместимости в установленном Chrome Stable/Beta ещё не завершена.** Перед включением подмен нужен полный успешный отчёт для точной версии Chrome. [Матрица приёмки](core-acceptance-matrix.json).

Исправлена конфиденциальность диагностического обмена: страница не получает список разрешённых сайтов и общий идентификатор применения. После обновления перезагрузите ранее обработанные страницы. Пакет содержит обезличенную сводку проверок без сырых логов. [Данные и ограничения](privacy.md).

## Установка и обновление

1. Распакуйте oboro-0.3.1.zip. Откройте chrome://extensions в Chrome.
2. Включите режим разработчика, выберите «Загрузить распакованное расширение» и папку **dist** из распакованного пакета.
3. Для обновления уже установленной локальной сборки замените файлы в прежней папке dist и нажмите кнопку перезагрузки на карточке расширения. При работе из проекта прежний путь остаётся тем же. Название в карточке изменится на oboro.
4. В сведениях о расширении разрешите пользовательские скрипты, если Chrome показывает этот переключатель. После изменения перезагрузите расширение.
5. Откройте настройки кнопкой **Open settings** из popup. Интерфейс по умолчанию английский; поле **Language → Русский** переключает его на русский и сохраняет выбор. Язык и тема выбираются вверху настроек и внизу popup. «Как в системе» учитывает настройки ОС; явный выбор сохраняется локально. Язык интерфейса не меняет языки регионального профиля.
6. Задайте профиль или подставьте пример «Берлин», затем сохраните. Выберите сайты и выдайте нужные доступы. Пустой список выбранных сайтов ничего не включает; исключения имеют приоритет.
7. Перед применением получите отчёт через пакет **oboro-probe-0.3.1.zip** с локальным Oboro Check и диагностическим расширением dist-probe. Завершите пробу и очистку, выключите диагностическое расширение и импортируйте полный JSON в обычном расширении.
8. Нажмите «Применить и перезагрузить выбранные страницы». Для выбранного iframe на другом сайте может понадобиться ручная перезагрузка родительской страницы.

## Выключение и ограничения

Общий выключатель снимает будущие регистрации и сетевые правила. Для возврата исходных API перезагрузите ранее обработанные страницы. При неподтверждённой очистке доступна команда «Отключить и повторить очистку».

Date, Intl и доступный Temporal.Now используют часовой пояс профиля по умолчанию. Явно заданные зоны и абсолютное время сохраняются. Неоднозначные строки дат вроде 01/02/2024 дают Invalid Date/NaN. Отсутствующий Temporal не создаётся.

Карта раскладки изменяет getLayoutMap. Физический ввод, key/code, сочетания и IME остаются системными. Геолокация возвращает фиксированный профиль с учётом нативных разрешений. После возврата из кэша страницы для геонаблюдений может потребоваться перезагрузка.

Workers, непрозрачные контексты и неизвестный origin не получают базовую подмену. IP и хранилища сайтов не изменяются. Диагностика показывает наблюдавшиеся документы и ограничения; она не подтверждает отсутствие всех утечек.

Разрешения: storage, activeTab, userScripts, scripting, declarativeNetRequestWithHostAccess, webNavigation. Доступ к HTTP/HTTPS-сайтам выдаётся отдельно. Удалённый исполняемый код отсутствует. Архивы не подписаны и не опубликованы в магазине; контрольные суммы находятся в SHA256SUMS.txt.
