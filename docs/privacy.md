# Конфиденциальность oboro

Обновлено 24 ноября 2026 года для версии 0.3.1, реализация runtime 7.

## Данные, доступные странице

Сайт получает региональные значения, заданные профилем: языки, геолокацию после разрешения, локаль, часовой пояс и запрошенную карту клавиатуры. Полный перечень приведён в [info.md](../info.md).

Из публичной диагностики удалены список host permissions, activationId и номера редакций. Политика сайтов и название профиля также не публикуются. Вместо объекта с внутренним состоянием используется функция без аргументов, возвращающая ограниченные состояния модулей и проверочный материал конкретного документа.

Каждый документ получает собственный 128-битный nonce из crypto.getRandomValues. Подтверждение связывает публичные состояния модулей с закрытой конфигурацией применения и origin через HMAC-SHA-256. Общий идентификатор и конфигурация остаются внутри зарегистрированного скрипта и фонового процесса. Страница не может задать nonce через запрос диагностики.

Фоновый процесс проверяет подтверждение, затем добавляет внутренние версии самостоятельно. Метаданные вкладки, фрейма, документа и origin берутся из Chrome. Сообщения со старыми открытыми идентификаторами, неизвестными полями, неверным подтверждением или другим origin отвергаются.

Проверки HMAC используют [эталонные векторы RFC 4231](https://www.rfc-editor.org/rfc/rfc4231.html) и независимое сравнение с node:crypto. Это проверка реализации протокола; она не заменяет приёмку установленного Chrome.

Наличие расширения и факт изменения API могут быть обнаружимы. Диагностика не является доказательством полной неотличимости браузера или покрытия всех контекстов. Сведения о применении в MAIN по-прежнему не считаются доверенной телеметрией сайта.

## Обновление уже открытых страниц

**После обновления расширения перезагрузите ранее обработанные страницы.** Старый runtime мог создать неизменяемый объект в документе; удалить его и прежние обёртки из существующего документа обновлением файлов невозможно. При обнаружении прежнего маркера новая реализация требует перезагрузку и не переиздаёт его закрытые данные в сообщениях.

## Локальные файлы и пакеты

Пользовательский экспорт конфигурации сохраняется только локальным скачиванием `oboro-config-<версия>.json`. Он включает введённые имя/координаты профиля, языки, настройки времени и клавиатуры, сайты, язык/тему интерфейса и подсказки host-доступов. Это приватные настройки; файлы исключены через .gitignore. В них не добавляются имя учётки Windows, имя компьютера, абсолютные пути, время экспорта, диагностические отчёты, номера локальных редакций, состояние применения, activationId и проверочные материалы. Версии приложения и формата записываются обязательно.

Журнал отката и одноразовая запись восстановления языка/темы остаются в локальном хранилище расширения и не включаются в экспорт. Результат записи проверяется чтением; незавершённый импорт восстанавливает предыдущие настройки до обработки следующих команд. Импорт не выдаёт и не отзывает разрешения Chrome, не включает подмены и не переносит доказательства совместимости. [Контракт формата](configuration-format.md).

- Старые логи и сырой отчёт реального браузера удалены. Старые архивы и распакованные копии сборок с прежней реализацией удалены при очистке.
- Упаковка не сохраняет консольный вывод в файл и не добавляет логи в ZIP. Вместо него создаётся verification-summary.json: версия приложения, команда проверки, булевы результаты и числовые счётчики тестов. Имена учётных записей, абсолютные пути, наблюдения браузера и время его использования туда не записываются.
- Файлы локального стенда включаются в диагностический архив по явному списку. Посторонние JSON-отчёты и локальные файлы рядом с кодом стенда не включаются.
- .gitignore исключает зависимости, сборки, артефакты, логи, диагностические экспорты, HAR, профили браузера, приватные ключи, сертификаты и локальные файлы окружения. Шаблоны .env.example, .env.sample и .env.template разрешены; они должны содержать только примеры.

Повторно проверены исходники, документация, зависимости, сборки, ZIP и метаданные изображений. В содержимом и именах файлов не обнаружены имя локальной учётной записи, имя компьютера, абсолютные пути профиля пользователя, приватные ключи или токены доступа. В зависимостях сохранены публичные имена и контакты авторов, лицензии и учебные примеры; тестовые адреса и профиль Берлина являются синтетическими данными. Из исторических отчётов удалены служебные цитаты из переписки и подробности попытки установки.

Правила .gitignore проверены самим Git в изолированном временном репозитории, включая вложенные сборки и логи, секреты, разрешённые шаблоны и исходники. Правила действуют на неотслеживаемые файлы; они не удаляют уже записанные данные из индекса или истории Git. Основной README и инструкции пакетов доступны на английском и русском; английский используется по умолчанию.

При ручном экспорте отчёта Oboro Check пользователь всё ещё может сохранить реальные языки, часовой пояс, версию Chrome, идентификатор диагностического расширения и времена запросов. Такой отчёт предназначен для локальной проверки совместимости; перед публикацией его нужно обезличить. Расширение хранит профиль и состояние применения локально в Chrome. Удаление проектных логов не удаляет настройки установленного расширения.
