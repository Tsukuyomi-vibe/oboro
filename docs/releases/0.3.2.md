# oboro 0.3.2

26 ноября 2026 года.

Обязательно только название профиля. Все остальные поля необязательны: пустое поле сохраняет исходное значение текущего браузера. Название можно ввести и сохранить без ошибки широты. Ноль остаётся заданной подменой; `unknown` / `неизвестно` означает явный null для высоты, точности высоты, скорости и направления. Очистка такого поля выбирает исходное значение браузера.

Частичная геолокация заменяет только выбранные поля в каждом нативном get/watch-ответе, сохраняя остальные координаты, timestamp, ошибки и разрешения. Если браузер не получил позицию, возвращается его ошибка. Полностью заданные геопрофили сохраняют прежнее поведение. Пустые языки не меняют navigator и Accept-Language, локаль и пояс работают независимо, системная карта остаётся нативной.

Экспорт записывает `oboroVersion: "0.3.2"` и `schemaVersion: 2`. Профиль с одной широтой переносит только эту подмену: локаль, пояс, языки и остальные значения принимающего ПК не заменяются сохранёнными значениями другого компьютера. Старые конфиги v1 и старые профили читаются с прежней семантикой; опубликованные schema/fixture v1 сохранены. Подробнее: [контракт конфигурации](../configuration-format.md).

Автоматические проверки охватывают все необязательные инпуты, независимые модули, get/watch/clear, старые конфиги, импорт поверх полного профиля, удаление старых правил и два разных синтетических окружения с одним JSON. Итог typecheck, двух сборок, аудита и тестов находится в `artifacts/verification-summary.json` внутри основного ZIP. Сырые логи не сохраняются. Палитра не менялась; расчёт контраста для текущих токенов включён в пакет.

Приёмка установленного Chrome Stable/Beta ещё не завершена. Результаты Node/VM/DOM не заменяют нативные доказательства. После обновления перезагрузите расширение и ранее обработанные страницы; прежний runtime 7 требует перезагрузки перед применением runtime 8.
