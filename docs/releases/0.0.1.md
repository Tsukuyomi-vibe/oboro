# oboro 0.0.1

28 ноября 2026 года.

По запросу пользователя версия приложения заменена на 0.0.1, а текущего переносимого конфига — на schemaVersion 1. Все возможности и исправления предыдущей версии 0.3.3 сохранены: шесть параметров подмены, только название как обязательное поле, исходные значения браузера для пустых полей, английский интерфейс по умолчанию с выбором русского, темы и безопасный экспорт/импорт.

Новый JSON содержит oboroVersion 0.0.1 и schemaVersion 1. Исторические полные v1 и файлы v2/v3 остаются доступными для импорта. Новый v1 из 0.0.1 строго отвергает пять удалённых геонастроек; исходный полный v1 распознаётся по версии экспортёра и наличию удалённых полей. Только реально отброшенные поля вызывают пояснение в предпросмотре. Оригинальная схема v1 сохранена в schemas/legacy; новая имеет отдельный идентификатор. Подробнее: [формат конфигурации](../configuration-format.md).

Служебная версия локального профиля остаётся 3, runtime остаётся 9. Ключи хранилища, счётчики, политика сайтов, разрешения и поведение подмен не менялись. Нумерация переносимого JSON независима от внутреннего хранилища.

Сборка включает обезличенную сводку проверок без сырых логов. Проверка установленного Chrome Stable/Beta остаётся незавершённой.
