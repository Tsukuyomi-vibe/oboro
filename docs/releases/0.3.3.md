# oboro 0.3.3

27 ноября 2026 года.

Удалены пять настроек геолокации: точность координат, высота, точность высоты, скорость и направление. Их больше нет в форме, сводке профиля, актуальном примере и новых JSON-конфигах. Доступны только широта и долгота; название остаётся единственным обязательным полем.

Экспорт использует schemaVersion 3 и oboroVersion 0.3.3. Схемы/фикстуры v1/v2 сохранены. Их адаптеры проверяют старый файл, отбрасывают пять удалённых настроек и сохраняют поддерживаемые параметры, сайты и предпочтения интерфейса. Предпросмотр предупреждает об этом изменении. V3 отвергает удалённые поля; они не попадают обратно в сохранённый профиль или экспорт. Подробнее: [контракт конфигурации](../configuration-format.md).

Геолокация получает нативную позицию и заменяет только заданные latitude/longitude. Остальные пять геополей, timestamp, опции, разрешения и ошибки остаются браузерными. Прежний путь полной синтетической позиции удалён. При недоступности позиции возвращается нативная ошибка.

Проверки охватывают миграцию старых файлов, строгую схему v3, отсутствие удалённых настроек в UI/экспорте, сохранение всех пяти полей и нативных ошибок, get/watch/clear и перенос профиля между разными окружениями. Обезличенный результат полной сборки и тестов находится в artifacts/verification-summary.json внутри основного ZIP. Логи и сборки не публикуются в исходном репозитории.

После обновления перезагрузите расширение и ранее обработанные страницы для удаления старых обёрток runtime 8. Новая реализация — runtime 9. Приёмка установленного Chrome Stable/Beta остаётся незавершённой.
