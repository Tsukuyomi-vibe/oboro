Chrome compatibility check

Local fixture checks only

The regular extension build is not involved in this probe. A MAIN marker and test Accept-Language are installed only for selected localhost addresses. Browser languages, time and geolocation are not overridden.

  1. Runnpm run fixtureand open the four fixture addresses without the diagnostic build installed. Save the server baseline report as instructed.
  2. After installing this build, check the API with the Chrome toggle off and on. Record the observed state below; reload this page after changing the toggle.
  3. Prepare a baseline, open all four links, wait for observations to be recorded and collect the report.
  4. Arm the probe, open the four armed links and collect the report.
  5. Remove the probe, open the four off links and collect the report again. Export the JSON.

Chrome 138+: enable “Allow User Scripts” in extension details; earlier versions use Developer mode. This tool does not change the Chrome toggle or use late injection.
