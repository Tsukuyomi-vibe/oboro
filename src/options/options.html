Profile parameters

Enter 1 to 10 tags separated by commas or spaces. The first language is used for navigator.language; the order determines Accept-Language.

Only getLayoutMap changes, when the Keyboard Map API is available. Typing, KeyboardEvent.key/code, shortcuts and IME keep their system behavior. Apply the profile and reload pages to change the map.

Scope

Switching keeps your site and exclusion lists. It does not request new permissions. In “All sites” mode, future access grants also select those addresses; exclusions always apply.

API overrides apply to the document; the network header applies to the request destination. Exclusions take priority over inclusions.

Chrome compatibility

Before applying for the first time, import a full compatibility report from Oboro Check. It verifies that the extension runs before site scripts in your Chrome version. Overrides remain off if the report fails or is incomplete.

Document coverage

Only observed documents are shown. Diagnostics do not prove the absence of all leaks. Returning from BFCache does not apply a new profile revision.

Workers: no baseline overrides.Site Dedicated, Shared and Service Workers are not covered. Opaque about:blank/srcdoc/blob contexts are skipped unless their HTTP/HTTPS scope is verified.

Geolocation watches stop when the page is left. A reload may be needed to resume them after returning from cache.
